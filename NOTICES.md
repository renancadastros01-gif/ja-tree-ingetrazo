Los archivos propios de JA Tree se ofrecen bajo GPL-3.0-or-later; véase LICENSE.
Los archivos Python e iconos SVG incluyen el identificador SPDX correspondiente.

JA Tree es un plugin para IngeTrazo, desarrollado por Marco Sumari Tellez y sus
colaboradores bajo GPL-3.0-or-later. Utiliza sus API y depende de la instalación
del anfitrión. El código del anfitrión no se distribuye dentro de estos paquetes.

El plugin utiliza Python, PySide6/Qt y NumPy proporcionados por el anfitrión.
Sus distribuciones, licencias y avisos respectivos pertenecen a esos proyectos;
sus binarios no están incluidos en el ZIP de JA Tree.

El nombre visible es JA Tree. El nombre de carpeta outliner y los identificadores
internos existentes se conservan para actualizar instalaciones anteriores sin
crear una segunda extensión ni perder preferencias.
